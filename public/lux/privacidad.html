Política de privacidad de Lux

Lux es una aplicación de uso estrictamente personal. Solo la usa su propietaria, con su propia cuenta de Google.

  • Los datos de Google (correo, calendario, documentos y contactos) se usan únicamente para dar servicio a la propietaria.
  • No se venden, no se ceden ni se comparten con terceros.
  • No se usan para publicidad.
  • El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado.
